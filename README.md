# ZELLER — Celebrate You

Premium editorial website prototype using the ZELLER brand identity and assets extracted from the supplied brand manual.

## Preview locally

Keep `index.html` beside the complete `assets/` folder. Run:

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Media is stored locally

- All website photos, the official ZELLER logo, symbol and icon assets are in `assets/`.
- All three chandelier motion placeholders are MP4 files in `assets/videos/`.
- The MP4s are local motion treatments generated from ZELLER brand imagery. They are not live client/product footage.
- Local still-photo fallbacks remain visible if autoplay is blocked.
- No Pexels video links, external image hosts, base64 media URLs, or relative paths outside the repository are required.

## GitHub Pages

Open repository Settings → Pages. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save. The published site should appear at:

`https://priyanshu21112003.github.io/zeller-premium-website/`

## Prototype limitations

Product names and specifications are sample concepts. Contact and newsletter forms are demonstration interactions and are not connected to a CRM. Replace sample content with approved catalogue details before production.
